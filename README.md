# 4VGym API con BBDD Relacional (Entity Framework Core)

Proyecto de acceso a datos para la gestión del gimnasio **4VGym**, unificando la API REST de `4VGymAPI` con la persistencia en base de datos SQL Server mediante Entity Framework Core (`4VGymEF`).

## Características
- API REST documentada con Swagger/OpenAPI.
- Patrón Repositorio para la separación de responsabilidades.
- Persistencia relacional con Entity Framework Core sobre SQL Server.
- Validaciones en DTOs y lógica de negocio.
- Script SQL para la inicialización y carga de datos de prueba.
